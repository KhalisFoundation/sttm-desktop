What gets downloaded, and credit
  • lines.csv (GAB answer key: verseId, start_s, end_s, source = human), shabads.csv (shabadId or bani:N, start_s, end_s, source = human), verse_timestamps.csv (verseId, timestamp_seconds: the layout of Jaspal's Hugging Face recordings) and segments.json (Karanbir Singh's benchmark format: start, end, shabad_id, line_idx, verse_id), all in one .zip-free bundle of separate downloads.
  • A pangti ends where the next mark starts; X marks a pause (alaap, katha, silence), which ends the pangti before it. Labels from this page are human labels: GAB scores pangti only on human or ear-checked keys.
  • Shabad and Bani text comes from BaniDB (the same ids as STTM Desktop). Pangtis are always shown whole.
  • The draft is kept in this browser while you work (per recording id); download the files to keep them.
  • The idea of stamping each pangti with number keys while listening comes from Karanbir Singh's annotate tool for the Live Captioning for Gurbani Kirtan benchmark. Thank you.
